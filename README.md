# Az „Álomcsapat” tervezése és dinamikája

Iskolai projektfeladat egy tudatosan összeállított projektcsapat működéséről.

## A projekt témái

- tudatos csoportösszeállítás
- csapatszerepek
- szakmai és szociális kompetenciák
- kommunikációs stratégiák
- motiváció és pszichológiai biztonság
- SCARF-modell:
  - Status
  - Certainty
  - Autonomy
  - Relatedness
  - Fairness

## Fájlok

- `index.html` – a projekt teljes tartalma
- `style.css` – megjelenés és reszponzív elrendezés
- `script.js` – egyszerű navigációs interakció

## Használat

Nyisd meg az `index.html` fájlt egy böngészőben.
